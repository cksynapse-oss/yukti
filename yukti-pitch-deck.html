Core Engine

3-pass matching

Pass 1 — ExactGSTIN + Invoice# + Amount70–80%
Pass 2 — FuzzyWeighted scoring (amount, date, similarity)15–20%
Pass 3 — SmartMany-to-one consolidation, subset-sum3–5%

Match rate: ≥ 98%. False positive rate: < 0.1%.

Every mismatch = ₹ quantified

  • Books only → vendor follow-up auto-generated
  • Portal only → ITC you're missing, action needed
  • Amount mismatch → ITC at lower value, flagged
  • Duplicate → excess ITC risk, urgent

Dashboard sorts by ₹ impact descending. This turns Yukti from "lists mismatches" into "recovers money."
